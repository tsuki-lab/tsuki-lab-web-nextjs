しんぷるカウンターは、わんコメ連携対応のシンプルなカウンターアプリケーションです。手動カウントと初見コメント自動集計の2つのモードを備えています。

## 必要なもの

- OBS Studio
- わんコメ（OneComme）

## 導入手順

### 1. わんコメにテンプレートとして登録する

Boothからダウンロードしたファイルを、わんコメのカスタムテンプレートとして登録します。

### 2. OBSにブラウザソースとして追加する

わんコメのカスタムテンプレート追加後に表示されるURLを、OBSのブラウザソースに設定します。推奨サイズは幅400px×高さ300pxです。

### 3. モードを選ぶ

- **手動カウントモード**: 左クリックで+1、右クリックで-1。リセットボタンで0に戻せます
- **初見カウントモード**: わんコメから配信コメントを受信し、初見コメントを自動集計します（コメントIDによる重複カウント防止つき）

## カスタムCSSで見た目を変更する

OBSのブラウザソースでカスタムCSSを設定することで、文字色・サイズ・フォント・影などを自由に変更できます。

```css
.counter-display {
  color: red;
  font-size: 96px;
  font-family: sans-serif;
}
```
