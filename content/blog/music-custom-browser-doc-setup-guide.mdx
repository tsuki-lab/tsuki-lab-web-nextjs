歌詞と音源をワンクリックで流せるツールは、歌枠配信で音源と歌詞をワンクリックで再生・閲覧できるカンペ用ミュージックプレイヤーです。曲を登録しておけば、再生位置に合わせて歌詞が自動でスクロールします。ローカル音源とYouTubeのどちらにも対応しているので、手元の音源ファイルとYouTube上の楽曲を同じライブラリで管理できます。

## 必要なもの

- OBS Studio
- Node.js（v18以上、ビルドする場合のみ）

## 導入手順

### 1. ビルドする（またはビルド済みファイルを受け取る）

```bash
npm install
npm run build
```

`dist/index.html` が生成されます。ビルド成果物はこの1ファイルだけなので、別のマシンでビルドしてこのファイルだけをコピーして使うこともできます（その場合、使う側のPCにNode.jsは不要です）。

### 2. OBSのカスタムブラウザドックに登録する

OBSメニューの「ドック」→「カスタムブラウザドック」から、ドック名を入力し、URL欄に `dist/index.html` の絶対パスを `file://` 形式で指定します。

macOSの場合:
```
file:///Users/<ユーザー名>/.../music-custom-browser-doc/dist/index.html
```

Windowsの場合、エクスプローラーで `dist\index.html` をShift+右クリックして「パスのコピー」し、先頭に `file:///` を付けて `\` を `/` に置き換えます。

### 3. 曲を登録する

「+ 追加」から曲名・音源（ローカルファイルまたはYouTube URL）・歌詞を入力して保存します。YouTubeの場合は曲の長さも入力してください。

## 主な機能

- 曲の検索（ひらがな/カタカナ・全角/半角を同一視）
- 手動順・曲名・アーティスト・追加日時での並び替え、ドラッグでの手動並び替え
- 再生すると3秒のカウントダウン後に自動再生、歌詞が再生位置に合わせて自動スクロール
- マスター音量とトラック別の音量補正（0〜200%）で曲間の音量差を調整
- 歌詞の装飾（太字・斜体・取り消し線・文字色）

データ（曲・音源・歌詞）はブラウザ内（IndexedDB）に保存されます。OBSのドックと通常ブラウザではデータが共有されない点に注意してください。
